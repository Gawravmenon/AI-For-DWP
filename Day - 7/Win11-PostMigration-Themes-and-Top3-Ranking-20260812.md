### 1) Authentication and AVD sign-in lockouts (Count: 7, Severity: Blocker)
Why it ranks here: Highest-volume blocker and complete work stoppage; users cannot access AVD or are repeatedly locked out, creating immediate operational risk.
Manager sentence: "Our top risk today is AVD/authentication lockouts affecting 7 users with total inability to work, so we need immediate remediation and proactive comms."

### 2) OneDrive missing files/sync error (Count: 4, Severity: Blocker)
Why it ranks here: Blocker-level data availability issue with deadline impact (reports/meetings), and no reliable user-side workaround when files appear missing.
Manager sentence: "OneDrive file loss/sync failures are our second highest priority because 4 users report missing business-critical files that block deliverables."

### 3) Shared drive access denied (S:/Finance) (Count: 3, Severity: Blocker)
Why it ranks here: Lower volume than some friction themes, but still a hard blocker tied to finance workflows and month-end reporting.
Manager sentence: "Shared drive access failures for Finance are priority three because even at 3 users, this is a hard blocker on core reporting activity."

## Note on Severity-Weighted Ranking
This ranking intentionally prioritizes blocker themes over higher-count minor/friction themes; for example, minor UI changes (7 comments) were not prioritized above blocker issues.
